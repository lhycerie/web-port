# China De Oro — Portfolio

Personal developer and UI/UX designer portfolio showcasing full-stack projects, leadership roles, and graphic designs

**Live Site**: [lhycerie.online](https://lhycerie.online)

---

## Pages & Overview

- **`project/index.html`** — Main landing page
- **`project/roles.html`** — Leadership & experience timeline
- **`project/graphics.html`** — Gallery 
- **`project/moreaboutme.html`** — Personal info
---

## Tech Stack

- **Core**: HTML5, CSS3, JS
- **Libraries**:
  - [Lenis](https://github.com/darkroomengineering/lenis)
  - [GSAP & ScrollTrigger](https://gsap.com/)
  - [Shaders](https://github.com/paper-design/shaders)


---

## Project Structure

```text
webdev-portfolio/
├── project/
```
